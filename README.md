# ViajaBarato

PWA responsivo para explorar voos, hotéis, resorts all inclusive e passeios. A aplicação usa um mecanismo demonstrativo de estimativas e abre parceiros externos para comparação e emissão.

## Executar localmente

Requer Node.js 18 ou mais recente.

```bash
npm start
```

Abra `http://localhost:3000`.

## Observação

Os valores exibidos são estimados e não representam inventário ou preços em tempo real. A confirmação deve ser feita no site do parceiro.
